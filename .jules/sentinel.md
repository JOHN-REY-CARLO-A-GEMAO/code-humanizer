## 2026-08-11 - Prompt-Driven Security in AI Agent Skills
**Vulnerability:** In prompt-driven AI Agent Skills (such as code-humanizer), instructions to simplify, clean up, or humanize code can lead the agent to strip away critical defensive layers, input validations, or sanitizations in the name of removing "AI-generated looking code" or "over-defensive error handling."
**Learning:** For example, removing SQL parameterization, removing authentication checks, or bypassing input validation are extremely dangerous actions. A human developer under a tight deadline might omit them, but a security-aware agent skill should actively protect these security layers while still humanizing the presentation.
**Prevention:** Integrate a first-class security-aware safety check directly into both `SKILL.md` (the prompt definition) and `README.md` (the documentation) to explicitly prevent the removal or weakening of security boundaries, input validation, and sanitization, regardless of the target code context.
